During the First Cloud AI Journey program, I had the opportunity to study AWS through a structured learning path, practice individual services, and record the results in a worklog. The program helped me connect theoretical knowledge with practical deployment tasks.

### Overall evaluation

1. **Learning environment:** The learning path is divided into weekly topics, making it easier to track progress and focus on each AWS subject.
2. **Mentor / team admin support:** The guides, announcements, and communication channels provided useful direction when I faced difficulties during hands-on practice.
3. **Relevance to my major:** The content is relevant to software development and cloud engineering, especially networking, servers, storage, databases, and containers.
4. **Learning and skill-development opportunities:** I practiced reading technical documentation, configuring AWS services, verifying results, troubleshooting, and writing technical reports.
5. **Culture and teamwork:** Sharing resources and discussing problems within the group created a supportive learning environment and allowed me to learn from other members’ experiences.
6. **Support for interns:** The program provided a clear learning path, reference materials, and expected deliverables, which helped me organize my study time proactively.

### Most satisfying part

What I liked most was the combination of theory and hands-on AWS practice. Completing each week made my progress visible, from creating an account and managing costs to deploying resources such as EC2, S3, RDS, and Lightsail.

### Areas for improvement

The program could add topic-based live Q&A sessions and checklists for common troubleshooting cases. This would help beginners identify the causes of configuration or permission issues more quickly.

### Suggestions and wishes

I hope the program continues updating its content with newer AWS services, adds more multi-service integration exercises, and provides opportunities to present the final work and receive practical feedback.
